Help / conventions

Tools. Hinge / shear hinge: click anywhere on a member to insert the selected release there (the member is split at that point), click a node to apply it to every member end at that node, or click close to a member end to release that end only; clicking again with the same type removes it. Add node on a member splits it while keeping continuity; Delete on an intermediate node of a straight member merges the two segments again.

Joints. All rigid member ends meeting at a node are merged into one rigid body (the node's host); every other end connects its own body to the host. Hinge: coincident point, free relative rotation (2 eq.). Shear hinge / slider: no relative rotation, relative translation only along the free direction (↕ vertical or ↔ horizontal, or custom angle) (2 eq.). Roller: only the translation normal to the free direction is restrained; sliding and rotation are free (1 eq.). The slot / rolling surface is fixed to the host body. Supports act on the host body.

Counting. Every member is a rigid body (3 DOF). W = n − m, f = n − rank J (actual DOF), s = m − rank J (redundant constraints). If f > 0 and s > 0 a second-order test decides between an instantaneously unstable system (no finite motion) and a finite mechanism. Closed rigid loops are treated as single rigid bodies; their internal indeterminacy (3 per closed loop) is not included in s.

Display. Each rigid body has its own colour; OI, OII, … are instantaneous centres (dashed radii to the body's nodes); red arrows are node velocities (one per attached body, so relative sliding at a shear hinge is visible); dashed members show the linearised virtual displacement. For an instantaneously unstable system dragging / animating only scales this virtual displacement – the structure itself cannot move.
